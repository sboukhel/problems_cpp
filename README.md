# problems_cpp

A collection of C++ programming exercises and small console games designed for learning core programming concepts, practicing problem solving, and improving logic-building skills.

## Overview

This repository contains:

- a set of beginner-to-intermediate C++ challenge files in `problems_level1/`
- two interactive console applications:
  - `MATH_GAME.cpp` — a math quiz game with configurable difficulty and operations
  - `SPS_GAME.cpp` — a simple stone-paper-scissors game against the computer

The project is ideal for students and developers who want to practice C++ fundamentals such as:

- functions and modular design
- loops and conditionals
- user input and validation
- random number generation
- score tracking and game logic
- console-based program structure

## Getting Started

### Prerequisites

Make sure you have a C++ compiler installed, such as:

- g++
- clang++

### Compile and Run

#### Math Game

```bash
g++ MATH_GAME.cpp -o math_game
./math_game
```

#### Stone-Paper-Scissors Game

```bash
g++ SPS_GAME.cpp -o sps_game
./sps_game
```

#### Run a Practice Problem

```bash
g++ problems_level1/problem01.cpp -o problem01
./problem01
```

## Learning Focus

This repository emphasizes practical programming habits, including:

- writing clean, readable C++ code
- structuring programs with functions
- solving logical challenges step by step
- testing and iterating through interactive programs

## Notes

This project is intended as a personal learning repository and a collection of coding exercises rather than a production application. It is best used as a foundation for practicing core C++ concepts.
